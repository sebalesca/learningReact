# Webportal

Este proyecto es un ejemplo base utilizando React, TypeScript y Vite.

## Scripts disponibles

- `npm run dev`: inicia el servidor de desarrollo en el puerto 80.
- `npm run build`: compila y genera la versión de testing.
- `npm run test`: ejecuta las pruebas con Vitest.

## Estructura

- `src/` contiene el código fuente principal.
- `index.html` es el punto de entrada del proyecto.
